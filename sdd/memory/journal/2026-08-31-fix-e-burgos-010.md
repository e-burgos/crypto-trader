# FIX-e-burgos-010 — 2026-08-31

## Que paso

El `ValidationPipe` global de `main.ts` (`whitelist` + `forbidNonWhitelisted`) parecia cubrir todo el backend, pero 8 endpoints no validaban nada: el pipe hace short-circuit cuando el metatype del parametro es `Object`, que es lo que recibe cuando el `@Body()` se tipa con un objeto inline, una interface o `any`. No hay error, ni warning, ni test que falle — el body simplemente entra crudo.

## Leccion

Un `@Body()` que no apunta a una **clase** con decoradores de `class-validator` desactiva el ValidationPipe global en silencio: al agregar un endpoint, el DTO es clase o no hay validacion. `apps/api/src/common/body-dto-validation.spec.ts` deja un guard estatico que recorre los controllers y lo detecta.

## Costo evitable

Auditar el pipe endpoint por endpoint es caro y se repite en cada auditoria; el guard estatico lo resuelve en un test y hace innecesario el barrido manual la proxima vez.
